Put your real images in this folder using these exact filenames,
and they'll appear on the site automatically (the placeholder
labels disappear on their own once a matching file is found):

  author-photo.jpg       -> your photo (top-left square)
  latest-book-cover.jpg  -> cover of your newest book
  back-cover.jpg         -> back-cover image/text of your newest book

Any common image format works (.jpg, .png, .webp) — just update
the filename in index.html to match if you don't use .jpg.
